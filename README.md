# Open EP Mapping Lab

A free, open, interactive course on cardiac electroanatomic mapping systems: how they
localize catheters, process electrograms and build activation and voltage maps.

**Site (pilot):** https://open-ep-mapping-lab.org/

**Status:** pilot. The first module (m03) is planned and in progress; no modules are complete yet.

**Education only.** Nothing here is for diagnosis, treatment or any clinical decision.

## What it will include

- 36 modules in six parts (see [docs/curriculum.md](docs/curriculum.md))
- Live in-browser figures, each labeled as exact, simulation, approximate model or schematic
- Runnable Python labs, with GNU Octave versions for the math foundations
- A formula sheet, glossary, interview questions and a public errata log

## Built on

- [OpenEP](https://github.com/openep) for mapping data formats and analysis
- [openCARP](https://www.opencarp.org/) for cardiac simulation
- [PhysioNet](https://physionet.org/) and [EDGAR](https://edgar.sci.utah.edu/) for public recordings

The course format is inspired by [OpenUltrasoundLab](https://openultrasoundlab.org).
