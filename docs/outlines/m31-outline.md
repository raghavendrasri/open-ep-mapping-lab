## The data

The Intracardiac Atrial Fibrillation Database (iafdb) on PhysioNet ([iafdb]; [goldberger2000]),
already used in the m03 lab and registered in `data/registry.json`. From its PhysioNet page,
checked 2026-11-04:

- 8 patients, 4 records each (32 records), named by catheter placement: `svc`, `ivc`, `tva`, `afw`.
- Intracardiac bipolar channels and surface ECG leads; the page is inconsistent about the number of
  ECG leads, so the lab reads the channel list from each header.
- Sampled at 1 kHz with 14-bit resolution; amplitudes are **uncalibrated**, so no voltage values in
  mV can be claimed from this database.
- Each record has a `.qrs` annotation file from an automatic detector (sqrs), not corrected.
- The `afw` headers note drug delivery (adenosine or isoproterenol) with approximate times.
- About 103 MB in total; license Open Data Commons Attribution License v1.0.

## Learning goals

After this capstone a reader can:

1. Load WFDB records reproducibly: pinned version, checksums, and a registry entry with license and
   citation.
2. Inspect real intracardiac signals: channels, noise, baseline wander, ventricular far-field
   activity and what "uncalibrated" means for analysis.
3. Remove ventricular activity: QRS detection, then average-beat subtraction on surface leads
   ([stridh2001]) and template subtraction on intracardiac channels ([ng2007tech]).
4. Compute dominant frequency (DF), organization index (OI) and cycle length over sliding windows,
   and report how stable each is.
5. Compare catheter placements and the periods before and after drug delivery, with honest
   uncertainty (bootstrap over windows, not over samples).
6. Write a reproducible analysis: a pre-stated plan, fixed parameters, and a figure set generated by
   code.

Prerequisites: m03, m04, m05 and m29.

## Section plan

Sections follow the module template (CLAUDE.md §3).

### 1. In 60 seconds

Real recordings are messier than simulations: the ventricles shout over the atria, baselines
wander, amplitudes are not calibrated and annotations are automatic. This capstone takes one public
database of intracardiac AF recordings from raw files to a short, reproducible report on activation
rate and organization at four catheter sites, and shows how each processing choice changes the
answer.

### 2. From the field

Lessons tied to verified sources:

- Average-beat subtraction leaves residual QRST energy when QRS morphology changes from beat to
  beat; a spatiotemporal method reduced the residual error to 58 % of that of plain average-beat
  subtraction in simulation ([stridh2001]).
- DF estimates depend on recording type, bipolar spacing, preprocessing, far-field ventricular
  signals and window length ([ng2007tech]); DF tracks activation rate only when its assumptions
  hold ([ng2007]).
- A frequency-domain organization index can be computed from the first four harmonic peaks of the
  spectrum ([everett2001]).
- In patients, DF maps built from electroanatomic points showed sites of high-frequency activity
  during AF ([sanders2005]).

### 3. Derivations

Notation: $x(n)$ sampled signal, $n_k$ detected QRS sample indices, $\bar t(m)$ average beat
template, $L$ template length, $N_b$ number of beats averaged, $\sigma^2$ variance of the activity
that is not time-locked to the QRS.

| ID | Equation | What it says | Badge of its figure | Check in `tests/` |
| --- | --- | --- | --- | --- |
| eq-m31-template | $\bar t(m) = \dfrac{1}{N_b}\sum_{k=1}^{N_b} x(n_k + m)$, $m = -L_1,\dots,L_2$ | Average beat aligned on QRS detections | exact | Numeric: recovers a known repeated waveform from a synthetic signal |
| eq-m31-abs | $x_A(n) = x(n) - \sum_k \bar t(n - n_k)$ | Average-beat subtraction leaves the atrial activity plus residual ([stridh2001]) | exact | Numeric: synthetic AF + known QRST; residual energy vs $N_b$ |
| eq-m31-template-noise | $\operatorname{Var}[\bar t(m)] = \sigma^2 / N_b$ | Activity not locked to the QRS averages out of the template as $1/N_b$ | exact | SymPy for the variance; numeric Monte Carlo |
| eq-m31-cl | $\mathrm{CL}_{\mathrm{DF}} = 1000/\mathrm{DF}$ (ms, Hz); $\mathrm{CV}_{\mathrm{DF}} = s_{\mathrm{DF}}/\overline{\mathrm{DF}}$ across windows | Cycle length implied by DF, and the window-to-window variability of DF | exact | Numeric: synthetic trains with known CL; variability of a stationary signal is near 0 |
| eq-m31-block-bootstrap | Confidence interval from resampling whole windows (or whole records), not single samples | Neighbouring samples are correlated; resampling them overstates certainty (links to m35) | simulation | Numeric: coverage of the interval on synthetic correlated data |

DF and OI are defined in m29 (eq-m29-df, eq-m29-oi) and are not repeated. Each derivation subsection
ends with a **Key takeaways** list.

### 8. Code lab and Self-check

Lab: `labs/python/m31_lab.ipynb`, a guided analysis with automatic checks (Python only). Data is
downloaded at run time to `data/cache/` with pinned checksums, as in m03; `EPML_REQUIRE_DATA=1`
forbids skipping.

| Part | Milestone | Data |
| --- | --- | --- |
| A | Download and verify the chosen records; add them to `data/registry.json` | iafdb |
| B | Inspect channels, units and annotations; plot a quality summary per record | iafdb |
| C | Ventricular activity removal: average-beat subtraction (surface) and template subtraction (intracardiac); residual check | iafdb + synthetic check |
| D | DF, OI and cycle length over sliding windows for each channel and site | iafdb |
| E | Compare the four placements and the pre-/post-drug periods with window bootstrap intervals | iafdb |
| F | Sensitivity: repeat D–E with alternative preprocessing; report the spread | iafdb |
| G | Generate the report figures from code; pre-stated plan at the top of the notebook | iafdb |

Self-check: at least 5 questions, numeric answers checked in tests.
